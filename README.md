# 运单数据处理测试项目
## 项目简介
使用Python+pandas读取Excel运单数据，完成数据清洗、空值校验、异常数据过滤，导出处理后的结果文件。
项目模拟软件测试流程，使用等价类、边界值方法设计测试用例，完成缺陷识别与回归验证。

## 技术栈
Python, pandas
测试方法：等价类划分、边界值分析、功能测试、缺陷回归

## 文件说明
- 运单处理.py：运单数据处理脚本
- test_report.md：项目功能测试报告
- 运单原始数据.xlsx：测试数据源

## 项目收获
熟悉测试用例设计思路，掌握Python脚本完成数据校验，具备文档撰写、缺陷闭环的实践经验。
